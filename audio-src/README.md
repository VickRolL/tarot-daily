# 音效素材说明（AiSounds / 爱声音坊）

本目录放**音效源文件**。抓下来的文件按下面的名字丢进 `audio-src/sfx/`，
我再跑一条命令把它们裁好、配平、编码进 `src/assets/audio/`。

为什么不用芒果灵创（mglc）做音效：实测过，它只有 `music` / `score` / `dubbing`
三种模式，**没有 SFX**。用「生成一声翻牌」的提示词提交，它交回来的是 **180.25 秒**
的整首曲子（两个变体都是）—— 不是没做好，是**没有「一声」这个出口**。
长氛围（BGM）它做得很好，短音效这条路在结构上就堵死了。

## 一、平台

**AiSounds（爱声音坊）**：<https://aisounds.cn/sounds/generate>

它跳转前的域名是 `aiwave.art`，两个是同一个产品。

⚠️ **搜「AIWave」会撞到一堆同名但完全无关的东西**，别走错：

| 域名 | 是什么 |
|---|---|
| `aiwave.art` → `aisounds.cn` | ✅ **就是这个**，Text-to-Sound-Effect，专做短音效 |
| `aiwave.live` / `api.aiwave.live` | ❌ 卖中国大模型 API 的网关，跟音频无关 |
| `audiowaveai` | ❌ 文本转语音的应用 |
| `airwaveai.com` | ❌ AI 工具导航站 |

另外有些收录站把 aiwave 写成「AI 歌曲生成工具、无 API、不支持二次集成」——
那是**错的**（它把两个产品混成一个了）。真实情况：

- 音效引擎是 **ElevenLabs Sound Effects**（1–30 秒，原生支持 Loop）
- 语义层用 DeepSeek V4 Pro 优化中文提示词 → **写中文比写英文效果好**
- 有「**项目音效包**」功能，就是为「UI 反馈音 / 游戏音效成组交付」做的
- 注册送 200 积分，无需绑卡；每日签到还有
- 商用：允许用于游戏 / 短视频 / 播客 / 广告项目，但不能转售或上传到素材站分发
- 生成结果可保存到「我的资产」再下载；导出格式 WAV / MP3 / OGG 都有

## 二、四个音：用途、时长、提示词

四个音**对应抽牌仪式的四拍**，长度是硬约束（写死在 `src/config/skin.js`
的 `DRAW_RITUAL` 里）——超了会撞到下一拍。

| # | 名字 | 在仪式里的位置 | 生成时长 | Loop |
|---|---|---|---|---|
| ① | `charge` | 点击之后、牌出现之前（`charging` 拍） | **1 秒** | 关闭 |
| ② | `burst` | 爆闪那一拍，牌登场 | **1.5 秒** | 关闭 |
| ③ | `flip` | 牌翻面 | **1.5 秒** | 关闭 |
| ④ | `reveal` | 牌面亮出、解读面板上来 | **5 秒** | 关闭 |

> **实际到货情况（2026-09-20）**：站点只支持**整数秒**，且计费 20 点/秒。
> 账户余额有限，四个音实际是这么生成的：
> `charge` 1s→实出 1.5s · `burst` 1s→实出 1.0s · `flip` 1s→实出 1.0s（修剪后 0.82s）·
> `reveal` **4s**（不是 5s —— 余额只够 4 秒）。
> 差的那 1 秒是余韵尾巴，4 秒的落点依然成立；以后有点数可以重生成 5s 直接覆盖，
> `scripts/build-sfx.py` 无需改（按 `_raw/` 里的文件重跑即可）。

### 共同要求（每条提示词里都要带上，别省）

```
不要：音乐、旋律、节奏、鼓点、打击乐、掌声；
      人声、语言、旁白、吟唱；
      低频轰响、爆炸、冲击感；
      尖锐的「咻」气流声；
      有音高的敲击（「咚」「嗒」「咔」这类）。

要：  柔软渐入的起音（不要突然出现）；
      安静的、有大厅混响的空间感；
      阴冷、克制、空灵。
```

**这半页「不要」不是客套，是第一轮四个音被否掉的全部原因。** 用户原话是
「和汽车加速的音效很像」「像拍了一下鼓」「翻牌也是鼓」「叮一声不符合体感」。
复盘下来三条都是同一个配方错的：「**有明确音高 + 快起音 + 低频能量集中**」——
人耳对这三件事的归类就是又硬又快的机械/打击事件。所以上面每一条都是冲着它去的。

---

### ① charge ——「屏息」

**1 秒。** 这一段是期盼感的来源：牌还没出现，只有空气在攒劲。
上一版这里用了上行扫频，结果被听成引擎拉转速。**所以绝对不要上升音调。**

```
一段 1 秒的极安静氛围铺垫音，只有空气在缓慢鼓起；像有人在幽暗的石砌大厅深处
缓缓吸气，气息很轻，环境里有一层几乎听不见的低频嗡鸣在慢慢变响。

起音必须是柔软渐入，音量从头到尾缓慢上升，结尾停在最饱满处；
不要上升的扫频音，不要「咻」的冲刺音效，不要合成器的滑音；
不要音乐、旋律、节奏、鼓点、打击乐、人声。
混响长，空间开阔，干净、克制、阴冷。
```

### ② burst ——「雾散」

**1.5 秒。** 爆闪那一拍：不是「捶一下」，是**雾被吹散**。

```
一声「雾气散开」的声音：像浓雾被无声吹散，一层柔和的空气向四周铺开然后慢慢消散。

起音要软（不要「啪」的瞬击）；完全没有低频轰响、爆炸、冲击感；
不要鼓点、打击乐、音乐、旋律、节奏；
不要尖锐的「咻」气流声。
可以有一层很远的低频嗡鸣垫底，但它必须慢慢淡入，不能一下砸下来。
安静、空灵、大厅混响。
```

### ③ flip ——「丝绢」

**1.5 秒。** 一张厚羊皮纸牌在木桌上翻面。**关键是不要有音高的「嗒」** ——
纸和绸本身没有音高，那个「嗒」正是不像的原因（上一版就栽在这）。

```
一张厚实的旧羊皮纸牌在木桌上被翻面的声音：纸与绸缎的轻柔摩擦，
带一点空气流动的沙沙声，落下时只有极轻的一声闷触。

分两层：先是一角被掀起时的细碎摩擦，接着整张翻过去时更宽的一层气流声。

绝不能是「咚」「嗒」「咔」这类有音高的敲击，不要木质敲击、不要木鱼声；
不要音乐、旋律、节奏、鼓点、打击乐。
近距离但柔软，安静、克制，带一点房间混响。
```

### ④ reveal ——「颂钵」

**5 秒。** 整场占卜的落点，余韵最长的一个音。
上一版是一声 659Hz、12ms 起音的「叮」，听起来像手机通知 —— 这次要**「嗡」起来**。

```
一声低沉的水晶颂钵被轻轻敲响并持续鸣响，长度 5 秒。

起音是柔和渐入的「嗡」，不是清脆的「叮」；音高低沉稳定，
带非常轻微的拍频起伏（两条几乎同频的基音缓慢打拍）；
金属泛音逐渐衰减，余韵很长。

绝对不要：清脆铃声、通知提示音、电子风铃、门铃、突然的瞬击；
不要音乐旋律、节奏、鼓点、人声。
像在一座幽暗石厅里回响，安静、庄严、空灵，混响很长很厚。
```

## 三、交付方式

**文件名必须完全一致**（我按名字认，不按顺序）：

```
audio-src/sfx/charge.mp3
audio-src/sfx/burst.mp3
audio-src/sfx/flip.mp3
audio-src/sfx/reveal.mp3
```

格式 `wav` / `mp3` / `ogg` 都行，后缀不用改，我按文件名主干匹配。

**每个音生成 2 个变体、全丢给我也行** —— 命名成 `charge-a.mp3` / `charge-b.mp3`，
我先量指标（时长、峰值、频谱质心、起音时间）再挑，挑不出来的地方再问你。

拿来之后我做四件事：

1. **裁**：去掉首尾静音、按上面那张表的时长裁齐、尾端加 30ms 淡出（防止截断爆音）
2. **配平**：四个音来自四次独立生成，响度一定参差 —— 统一按 RMS 对齐到同一档，
   否则「有的音听不见、有的音吓人」。这一步是必须的，不能省。
   **2026-09-20 实测补充（比想象的难，值得记着）**：
   - **峰值受限时 RMS 有数学上界**。flip 是「很轻的床体 + 一记 6ms 爆裂」，
     0.77% 的样本占了 4.83dB 能量；峰值钉在天花板时它的 RMS 上界只有 -17.3dB，
     离 -14dB 目标差 3.3dB，**靠限幅永远到不了**。
   - 到不了就只有两条路：接受偏差，或引入失真（软削顶）。flip 选了后者
     （-5.5dBFS 处软削顶，1.44% 样本），并且**逐素材决定** ——
     有音高的起音（reveal 的颂钵）被饱和会变成闷响，那就宁可抬天花板也不削顶。
   - 天花板不是越保守越好：站点总线增益只有 0.34（-9.4dB），
     留 -1.5dBFS 是白白浪费 1.2dB 的响度余量，现在用 -0.3dBFS。
   - **判据落在 mp3 解码结果上**：64kbps 单声道有 0.4~0.7dB 固有衰减，
     拿编码前 PCM 对目标会为了「数字好看」而过推响度。
   最终四个音解码后 RMS：charge -14.7 / burst -13.6 / flip -14.5 / reveal -14.7 dB
   （burst 按设计比其它高 1dB），最大偏离目标 0.7dB，全在可听辨门槛（1dB）内。
3. **编码**：压成体积可控的小文件进 `src/assets/audio/`
4. **接线**：改 `src/audio/sfx.js` 成「**素材优先、合成兜底**」——
   AI 素材缺失或解码失败时自动退回现有的合成实现，页面不会变哑巴。

> 想直接用耳朵验收：`audio-src/audition.html` 里四个音各一个播放器，
> 外加一个「按仪式节拍连播」按钮（节拍取自 audit-draw 的实测时间轴）。
> 它放的就是站点里真正在用的那四个文件、增益全为 1.0，所以听到的相对音量即页面上的。

顺带一提：合成那四个音的实现**会保留**，不删。它是 `file://` 直接打开、
或者素材加载失败时的兜底路径。
